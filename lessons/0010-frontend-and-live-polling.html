看懂页面如何调用 API 并自动更新

你将理解 HTML、CSS、DOM、fetch、async/await、事件监听和两秒轮询。

1. 三种前端文件各管什么？

HTML

static/index.html 定义标题、按钮、表格和弹窗等结构。

CSS

static/styles.css 决定布局、颜色、间距和响应式显示。

JavaScript

static/app.js 请求数据、响应点击并修改页面内容。

DOM

浏览器把 HTML 变成可由 JavaScript 查找和修改的对象树。

2. api() 是前端统一服务窗口

async function api(path, options = {}) {
  const response = await fetch(path, {
    headers: { "Content-Type": "application/json" },
    ...options,
  });
  if (!response.ok) throw new Error(...);
  return response.json();
}

async 表示函数包含异步操作，await 等待网络结果但不冻结整个浏览器。统一函数让错误处理和 JSON 解析只写一次。

3. 从 JSON 到页面

const data = await api("/api/status");
$("metric-articles").textContent = data.article_count;

$() 是项目自己的简写，内部调用 document.getElementById()。第二行把 JSON 中的文章数写进页面元素。

4. 事件把用户动作连接到函数

button.addEventListener("click", startCollection);

注册事件后，浏览器不会立即运行 startCollection；只有点击发生时才调用。表单提交、下拉变化和输入都使用类似方式。

5. 为什么页面能自动同步？

window.setInterval(pollLiveState, 2000);

页面每两秒调用一次 pollLiveState()，并行刷新采集状态与 AI 状态。后台任务完成后，下一轮查询就能看到新值。

state.pollInFlight 防止上一轮还没结束又启动下一轮；Promise.allSettled() 让一个状态接口失败时另一个仍可完成。

6. 列表不是自动更新的

实时状态会轮询，但关键词列表通常在进入页面、保存或手动刷新时重新加载。这解释了为什么数据库已更新后，旧页面可能需要重新进入或 Ctrl+F5。

7. 真实案例：关键词命中统计

新增一个统计展示通常要同时完成：

  1. 后端提供 /api/keyword-hit-stats。
  2. JavaScript 调用接口并保存数据。
  3. 渲染函数把结果写入表格或卡片。
  4. 在保存、采集完成或刷新时重新加载。
