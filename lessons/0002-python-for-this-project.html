1. 值、变量与类型

Python 程序处理的所有东西都是“值”。变量只是给值贴上的名字：

name = "通用关税政策（中文）"   # str：文字
lookback_days = 30             # int：整数
active = True                  # bool：真或假

= 在这里不是数学等号，而是“把右边的值交给左边的名字”。使用 # 开头的内容是注释，不会执行。

2. 列表与字典：项目最常见的数据容器

列表 list

一组有顺序的值，用方括号：

terms = [
    "关税",
    "反倾销",
    "反补贴",
]

terms[0] 得到第一个值 "关税"。

字典 dict

通过键查找值，用花括号：

keyword = {
    "name": "关税政策",
    "active": True,
}

keyword["name"] 得到 "关税政策"。

app/database.py 中的 DEFAULT_KEYWORDS 是一个元组，里面每一项都是字典；字典中的 match_terms 又是列表。这就是“容器里面还可以放容器”。

3. 条件、循环和函数

for term in match_terms:
    if term:
        print(term)
  • for：依次取出列表中的每一项。
  • if：只有条件成立才执行缩进内容。
  • 缩进：Python 用四个空格表示代码属于哪个结构。

函数把一段动作命名，避免重复：

def build_label(name: str, active: bool) -> str:
    if active:
        return name + "（启用）"
    return name + "（停用）"

name 和 active 是输入参数，return 是输出。类型标注先当作说明书阅读：name: str 表示输入应是字符串，-> str 表示返回字符串。

4. 如何从一段真实配置开始阅读

{
    "name": "通用关税政策（中文）",
    "match_terms": ["关税"],
    "context_terms": ["政策", "调整", "加征"],
    "exclude_terms": [],
    "lookback_days": 30,
    "active": True,
}
  1. 先看最外层：这是一个字典，描述“一组关键词策略”。
  2. 再看每个键：名称、主题词、语境词、排除词、天数、开关。
  3. 最后看嵌套值：主题词和语境词是列表，可以有多项。
