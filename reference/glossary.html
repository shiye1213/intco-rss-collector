Quick reference

先听懂大家在说什么

不要求一次背完。遇到陌生词回来查，并尽量把它对应到一个真实文件。

系统与网络

前端 Frontend
用户看到并操作的页面。本项目主要是 static/index.html、static/styles.css 和 static/app.js。
后端 Backend
在服务器进程中处理请求和业务规则的代码。本项目入口是 app/main.py。
API / 路由 Route
前后端约定好的“服务窗口”。例如浏览器请求 GET /api/status，后端返回 JSON 状态。
HTTP
浏览器、新闻站点和 API 服务之间传递请求与响应的规则。常见状态码有 200、403、429、500。
JSON
网络接口常用的数据文本格式，由对象、数组、字符串、数字、布尔值和 null 组成。
RSS / XML
网站发布更新的一种订阅格式；RSS 文档通常用 XML 表示，多篇新闻放在多个 item 中。

Python 代码

模块 Module
一个可导入的 Python 文件，例如 app/collector.py。
函数 Function
有名字、可重复调用的一段动作；输入是参数，结果可通过 return 返回。
类 Class / 对象 Object
类像机器图纸，对象是按图纸造出的具体机器。对象把数据和能操作数据的方法放在一起。
类型标注 Type hint
写给人和工具看的数据形状提示，例如 query: str 表示 query 应是字符串。
异常 Exception
代码无法正常继续时抛出的结构化错误；上层可以捕获它并决定重试、返回错误或记录失败。
异步 / 后台任务
耗时工作不阻塞当前页面请求；页面先得到“任务已开始”，再通过轮询查看进度。

框架、数据与 AI

FastAPI / Uvicorn
FastAPI 定义后端接口，Uvicorn 负责真正监听端口并把 HTTP 请求交给应用。
Pydantic
根据 Python 类型定义检查外部数据，把错误输入挡在业务逻辑之前。
SQLite / 表 / 行
SQLite 是保存在单个文件里的关系数据库；表像结构固定的表格，行是一条记录。
迁移 Migration
在保留旧数据的前提下修改数据库结构，例如增加一列或新建一张表。
LLM / Prompt / Token
LLM 是大语言模型；prompt 是输入指令；token 是模型处理文本时使用的计量单位。
429 / Retry / Backoff
429 常表示请求过多；retry 是重试，backoff 是逐渐延长等待，避免立刻再次撞上限流。
测试 / Mock
测试自动验证行为；mock 用可控的替身代替真实网络或收费模型，使测试快速、稳定。
术语必须最终回到代码中理解，而不是孤立背诵。
